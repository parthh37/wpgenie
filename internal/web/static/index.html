Security

IP reputation

Public blocklists of hijacked networks and addresses attacking servers right now, refreshed every 6 hours. Each site chooses whether listed clients are challenged or blocked (Site → Security). Verified search engines are never affected.

Server-wide lists

Apply to every site. Allowed addresses are never challenged, blocked or banned (your office, monitoring); blocked ones get nothing from any site.

Banned addresses

Clients that send attacks (SQL injection, scanners, brute force) are banned on every site automatically: 1 hour, doubling for repeat offenders.
